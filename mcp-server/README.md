# mcp-server/ — DTP v0.1 local MCP client (frozen)

> **Status: v0.1, frozen.** A stdio MCP server that drives the v0.1 NEAR contract from local credentials (plaintext keys in `.near-credentials/`). Superseded for the MVP by [`marketplace/`](../marketplace) and for the protocol by the v0.2 store ([`supabase/functions/dtp-store`](../supabase/functions/dtp-store)) and SDK ([`sdk/`](../sdk)). Kept for reference; not maintained.

**Reference only, not runnable support.** Normal build/dev/start/pack and direct compiled entry now refuse execution. Known vulnerable dependencies remain in the historical lockfile; they have not been patched. This client is excluded from the foundation release surface. See [the archive boundary and revival requirements](../docs/foundation/legacy-adapter-boundary.md). No live deployment or existing installed copy was changed by these repository guards.
